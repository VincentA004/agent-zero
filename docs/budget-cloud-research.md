# Low-cost open-weight cloud models for Agent Zero

**Checked 2026-10-23.** Catalog rates, free availability, provider policies and evaluations change often; recheck the linked model pages before configuring anything. This is research only: no inference calls, credit purchase, model download, or application configuration change was made.

## Recommendation

**Agent Zero selection judgment:** GLM 5.3 Flash is the better first trial for this user's combination of very low cost and usable modern capability. Ling is the lower-cost candidate, but saves only about $0.13/month in the stated workload while scoring substantially lower on the cited independent index. These are research-based trial choices, not a tested quality guarantee or an equivalence to a closed model from six months ago.

For a paid, very-low-cost default to test first, use **`inclusionai/ling-3.0-flash`**. OpenRouter currently shows $0.021/M input and $0.063/M output, 262K context, tool calling, JSON output (without JSON Schema enforcement), and a 65%-off Novita route. At the example usage below that is $0.189/month on Novita, or about $0.54/month at DeepInfra's displayed undiscounted $0.06/$0.18 rates. The model card is MIT licensed. Its independent Artificial Analysis (AA) indexes are modest (Intelligence 20.1, Coding 50.6, Agentic 19.3), so treat it as a cheap trial/default for ordinary conversation and bounded tool work, not a frontier substitute. [OpenRouter model/prices/benchmarks](https://openrouter.ai/inclusionai/ling-3.0-flash) · [official model card/license](https://huggingface.co/inclusionAI/Ling-3.0-flash)

Use **`z-ai/glm-5.3-flash`** as the quality fallback: $0.0052/M input, $0.1985/M output, 1M context, tools and strict JSON Schema outputs. Example cost is $0.321/month. AA's independently measured Intelligence Index is about 42, materially above Ling's 20.1, though the output rate is about 3.15× Ling's promotional rate and GLM can spend substantial reasoning/completion tokens. It is MIT licensed. Cap reasoning/output and inspect actual usage before routing all traffic to it. [OpenRouter model/prices/tools](https://openrouter.ai/z-ai/glm-5.3-flash) · [official model card/license](https://huggingface.co/zai-org/GLM-5.3-Flash) · [AA independent-index methodology](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index)

For free experiments, pin **`google/gemma-4-26b-a4b-it:free`** rather than relying on a random router. OpenRouter lists it at $0, 262K context, Apache 2.0, tools, and basic JSON output (no JSON Schema enforcement). AA's current release table estimates its Intelligence Index at 17; independent evaluation is still forthcoming, so do not treat that as a final measured score. For coding-only experiments, **`cohere/north-mini-code:free`** is another Apache 2.0 option with 256K context and schema-based tool use; I found no comparable independent general/agentic score to support a quality recommendation. [Gemma free endpoint](https://openrouter.ai/google/gemma-4-26b-a4b-it:free) · [AA Gemma release evaluation](https://artificialanalysis.ai/models/releases/gemma-4-26b-a4b) · [North Mini Code free endpoint](https://openrouter.ai/cohere/north-mini-code:free)

“About six months behind” is not a measurable model property. AA provides a useful but incomplete snapshot: its latest index combines ten independent tests across reasoning, science, coding and work tasks. As of this check, its displayed top closed models score 56–58, GLM 5.3 Flash is around 42, and Ling 3.0 Flash is 20.1. These scores do not map to a time delay; task fit, reasoning settings, prompt length and tool harness change the result. [AA index and methodology](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index)

## Free routes, limits and privacy

OpenRouter's [free model collection](https://openrouter.ai/collections/free-models) is a changing catalog. The router's exact ID is **`openrouter/free`**; it chooses a free model at random and filters for request features such as tools or structured output. That is convenient for throwaway experiments but makes outputs, provider privacy, latency and quality less reproducible than selecting a specific `:free` model. [Router page](https://openrouter.ai/openrouter/free)

OpenRouter currently states free models are capped at **20 requests/minute and 50/day** for accounts without purchased credits; after buying at least **$10 of credits**, the free-model daily ceiling rises to 1,000, still at 20/minute. Failed requests count against the daily cap. This is not a recommendation to buy credits: 50 free requests/day is below the example's 100 one-request conversations/day. Check current [pricing/limits](https://openrouter.ai/pricing) and your key's actual limits before relying on them.

Free does not mean a uniform privacy policy. OpenRouter says prompts are sent to the selected/automatically selected provider, providers differ on retention and training, and OpenRouter itself does not train on inputs/outputs. In particular, the **Laguna S 2.1 free** endpoint says prompts and outputs may be used for training and its free listing says it is going away October 31, 2026. Do not send private or proprietary context through a free route unless the chosen provider's terms are acceptable. [OpenRouter privacy policy](https://openrouter.ai/privacy/) · [Laguna S 2.1 free terms/status](https://openrouter.ai/poolside/laguna-s-2.1:free)

A provider's **open-weight license** is separate from its hosted inference offering: paying OpenRouter buys API processing, not a model license; conversely, a permissive weight license does not make hosted API usage free. MIT and Apache 2.0 are broad permissive licenses, while other open-weight terms can impose restrictions. Use the model card linked above for the exact release license.

## What changes the bill

The table assumes a single short request per conversation. Agent Zero can make several model calls in a single task and resend the growing chat/tool history each time, so real use can exceed it by multiples. A 2× increase in billable input/output tokens roughly doubles token cost. Reasoning tokens count as output usage; hidden reasoning can make billed completion usage larger than visible answer text. Set an output/reasoning cap where supported and use returned usage/cost fields to measure real sessions. [OpenRouter reasoning-token docs](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens)

Prompt caching can lower repeated-prefix costs only when the same provider supports it and receives a cacheable prefix. Ling 3.0 lists cache-read at $0.0042/M, while GLM lists $0.0052/M; OpenRouter routing/failover can affect cache hits. The estimates above assume no caching credit. [OpenRouter prompt caching guide](https://openrouter.ai/docs/guides/best-practices/prompt-caching)

OpenRouter Standard has no minimum spend or lock-in, but its pricing page lists a **5.5% fee on credit purchases**. Small monthly token estimates do not imply a small top-up is available; verify the current credit-purchase mechanics and your wallet balance first. Do not enable auto top-up without setting a cap. [Pricing](https://openrouter.ai/pricing)
